# Redesign Frontend Core & Shared UI Components

This plan outlines the steps to implement the "Clean SaaS Dashboard" aesthetic defined in your `frontend-design-guide.md`, focusing initially on the base configuration (colors, fonts) and the common UI components (`Card`, `Button`, `Badge`).

> [!IMPORTANT]
> **User Review Required**
> 
> 1. **Custom Tailwind Configuration**: Instead of hardcoding long shadow utilities like `shadow-[0_2px_16px_rgba(0,0,0,0.06)]` directly in the component files, I propose adding them as custom semantic shadows in `tailwind.config.ts` (e.g., `shadow-card`, `shadow-card-hover`). This keeps the code much cleaner and easier to maintain.
> 2. **Shadcn Customization**: We will be directly modifying the base components generated by Shadcn (like `button.tsx` and `card.tsx`). This means if you use the Shadcn CLI to update components in the future, you will need to be careful not to overwrite these custom styles.
> 3. **API Logic**: As requested, no business logic or API integrations will be touched during this phase.
